# 外壁塗装の窓口 - ホームページクローンプロジェクト

## プロジェクト概要

- **目的**: Webサイト https://gaiheki-madoguchi.com/ のフロントエンド部分のクローンを作成する
- **対象サイト**: 外壁塗装の窓口 (https://gaiheki-madoguchi.com/)
- **開発担当**: Claude (AI アシスタント)

## リポジトリ構造

```
/
├── css/        # CSSファイル
├── images/     # 画像ファイル
├── js/         # JavaScriptファイル
├── index.html  # メインHTMLファイル
├── Project.md  # プロジェクト管理ファイル
└── development_plan.md  # 開発計画書
```

## 主要機能

- レスポンシブデザイン（PC/タブレット/スマートフォン対応）
- ハンバーガーメニュー（モバイル表示時）
- カラーセレクター（メインビジュアル部分）
- フォームバリデーション
- FQQアコーディオン
- 都道府県別エリア検索
- スムーススクロール

## 技術スタック

- HTML5
- CSS3
- JavaScript（jQuery）
- SVG
